this is my first project on GitHub and I am setting up my lab environment 

I prefer to use virtual box because it's popular in the open source world. you can use it both on Windows and Linux PC environments. 

After installing the actual application, do not forget to download and install the virtualbox extension pack, which is the same version as this.

<img width="984" height="326" alt="image" src="https://github.com/user-attachments/assets/985f56b4-0a35-487b-a736-e936db1c4271" />

There are various methods of installing Kali Linux under VirtualBox. For convenience, we will proceed by importing a preinstalled VM image. Go to:

https://www.offensive-security.com/kali-linux-vm-vmware-virtualbox-image-download/

You will see two types of images here, 32bit and 64bit. If your Desktop Operating System supports running a 64bit virtual OS, it is recommended that you download it.

We will import the pre-installed Kali Linux VM machine just downloaded, into the VirtualBox environment.

After the import is done, the Kali Linux VM is ready for use. Click the green “Start” button to boot virtual machine.

<img width="1624" height="1403" alt="image" src="https://github.com/user-attachments/assets/f3be8278-3b9d-4ad3-802f-087820c4881a" />

Once the Importer is finished, boot up the virtual box, it may take awhile to start up, once done, enter kali as both username and password.
